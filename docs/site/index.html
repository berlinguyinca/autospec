What is autospec?

Autospec turns a natural-language feature description into a fully implemented, reviewed, and merged pull request — autonomously. It works with Claude Code, Codex CLI, and OpenCode.

  1. Define — autospec define "build me a TODO list CLI"
  2. Decompose — spec becomes a GitHub issue tree, auto-labelled
  3. Implement — each issue gets its own worktree, TDD loop, and self-review
  4. Merge — passing PRs land automatically; failures surface for human review

## Shared scripts (`$AUTOSPEC_SCRIPTS_DIR`)

Installed to `~/.autospec/scripts/` by every skill's `install.sh`.

### `autospec-watchdog.sh`

Reclaims stalled monitor workers by reconciling `process-heartbeats/<repo-slug>/*.json` files.
Runs flat-format migration on each tick: files with a `repo` field move to `<repo-slug>/`;
stale files without a `repo` field (older than 1 hour) are deleted.

```
Usage: bash autospec-watchdog.sh
Env:   AUTOSPEC_WATCHDOG_REPO        override repo for gh calls (derives <repo-slug>)
       AUTOSPEC_WATCHDOG_STALE_SECS   stale threshold (default: 1800)
       AUTOSPEC_WATCHDOG_RECLAIM_SECS reclaim threshold (default: 10800)
```

Exit: always 0. Prints `service-watch: nudged=N reclaimed=N ...` summary.

### `heartbeat-write.sh`

Writes a per-repo-scoped heartbeat to `~/.autospec/process-heartbeats/<repo-slug>/<issue>.json`.

```
Usage: heartbeat-write.sh --issue <N> --step <step> [--branch <b>] [--pr <p>] [--repo <owner/repo>]
Env:   AUTOSPEC_REPO   repo override (owner/repo format)
```

### `heartbeat-read.sh`

Reads heartbeat files from the caller's repo-slug subdir only (zero cross-repo bleed).

```
Usage: heartbeat-read.sh [--issue <N>] [--repo <owner/repo>]
```

Without `--issue`: prints all heartbeat file paths in the repo's subdir (one per line).
With `--issue`: prints the JSON content of that heartbeat, or empty if not found.

### `lint-issue.sh`

Quality-gate for GitHub issue bodies before they enter the `auto-implement` queue.

```
Usage: bash lint-issue.sh <issue-number> [--repo <owner/repo>]
       bash lint-issue.sh --help
```

Exit: 0 = pass, 1 = fail with diagnostics.

### `lint-implementation.sh`

Scans implementation PRs for 10 rule violations (OUT_OF_SCOPE, MISSING_TEST, COMPLEXITY,
SECURITY, TODO_LEFT, MOCK_DB, DOC_OUT_OF_SYNC, HALLUCINATED_API, DUPLICATE_CODE,
INVENTED_CONFIG).

```
Usage: bash lint-implementation.sh <pr-number> [--repo <owner/repo>]
       bash lint-implementation.sh --help
```

Exit: 0 = pass, non-zero = at least one rule triggered.

### `sizing-check.sh`

Checks that an issue's estimated size fits the declared `ctx:*` label budget.

```
Usage: bash sizing-check.sh <issue-number> [--repo <owner/repo>]
```

### `listener-match.sh`

Pattern-matches a conversation snippet against autospec-listen trigger keywords.

```
Usage: bash listener-match.sh [--text <text>]
```

### `ci-wait.sh`

Polls GitHub Actions for a PR's CI status until pass/fail/timeout.

```
Usage: bash ci-wait.sh <pr-number> [--repo <owner/repo>] [--timeout-secs N]
```

## Doc-generation scripts (`$AUTOSPEC_SCRIPTS_DIR`)

Installed by `skills/autospec-shared/install.sh`.

### `reverse-engineer.sh`

Orchestrates the 5-step reverse-engineer pipeline: inventory → tree-sitter walk → cluster →
emit-specs → summary JSON.

```
Usage: bash reverse-engineer.sh --repo-root <dir> [--docs-dir <dir>] [--date <YYYY-MM-DD>]
```

Exit: 0 = success, 1 = usage error or pipeline failure.

### `gen-llms-txt.sh`

Generates `llms.txt` (≤200 lines index) and `llms-full.txt` (full concatenated content) at repo root.

```
Usage: bash gen-llms-txt.sh --repo-root <dir> [--cluster-json <file>]
```

### `check-doc-drift.sh`

Deterministic drift checker. Parses `autospec-doc-scope` blocks, computes changed source
files from a PR diff, and flags sections whose scope matches but whose content wasn't updated.

```
Usage: bash check-doc-drift.sh <pr-or-diff> [--repo <owner/repo>]
       bash check-doc-drift.sh --working-tree
```

Exit: 0 = clean, 1 = drift, 2 = missing-scope.

### `gen-docs-from-spec.mjs`

Orchestrates doc generation from cluster output. Generates USER_MANUAL.md, API_REFERENCE.md,
ARCHITECTURE.md while preserving human-edited sections (non-`generated: true`).

```js
import { generateDocs } from './gen-docs-from-spec.mjs';
const result = await generateDocs({ clusters, specs, existingDocs, outputDir, repoRoot });
// result.files: Array<{ path, content, written, preserved_sections, section_anchors }>
```

### `gen-llm-manifest.mjs`

Generates `docs/.llm-manifest.json` per spec §5b. Schema version 1.0.

```js
import { writeManifest } from './gen-llm-manifest.mjs';
const { written, path } = await writeManifest({ clusters, repo, repoRoot, outputPath });
```

### `gen-assistant-prompt.mjs`

Generates `docs/ASSISTANT_PROMPT.md` paste-ready system prompt per spec §5c.

```js
import { writeAssistantPrompt } from './gen-assistant-prompt.mjs';
const { written, path } = await writeAssistantPrompt({ repo, repoRoot, outputPath });
```

### `gen-arch-diagram.mjs`

Generates mermaid module dependency graph embedded in `docs/ARCHITECTURE.md`.

### `scan-doc-scope.mjs`

Parses `<!-- autospec-doc-scope: ... -->` blocks into `{ section_path → globs }` map.

```js
import { scanDocScope } from './scan-doc-scope.mjs';
const scopes = await scanDocScope({ docFile });
// scopes: Array<{ heading, src, reason, generated }>
```

### `ai-review-doc.mjs`

LLM reviewer pass on auto-generated doc sections. Returns `high|medium|low` confidence grading.

### `loop-classifier-docs-extension.mjs`

Extends the Phase 4 self-heal loop classifier with doc-drift categories:
`failing_doc_drift`, `missing_doc_scope`, `failing_visual_stale`, `failing_ai_review_stale`,
`failing_manifest_stale`.

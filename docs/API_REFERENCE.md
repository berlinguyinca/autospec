## Shared scripts (`$AUTOSPEC_SCRIPTS_DIR`)

Installed to `~/.autospec/scripts/`. The top-level `install.sh` globs every repo-root
`scripts/*.{sh,mjs,ps1}` (excluding the install-time-only `scripts/lib/`) plus the entire
`skills/autospec-shared/scripts/` tree into `~/.autospec/scripts/` for all harnesses
(`claude|codex|opencode|all`), so new repo-root helper scripts ship automatically without a
hand-maintained list. The per-skill standalone installers (`skills/*/install.sh`) enumerate a
`SHARED_SCRIPT_FILES` subset as a stopgap for curl-based installs that lack the repo checkout.
The `tests/ship-completeness.bats` guard asserts every `${AUTOSPEC_SCRIPTS_DIR}`-referenced
script is in the shippable set and that no bare repo-relative script invocation remains in any
skill surface.

### `autospec-watchdog.sh`

Reclaims stalled monitor workers by reconciling `process-heartbeats/<repo-slug>/*.json` files.
Runs flat-format migration on each tick: files with a `repo` field move to `<repo-slug>/`;
stale files without a `repo` field (older than 1 hour) are deleted.

```
Usage: bash autospec-watchdog.sh
Env:   AUTOSPEC_WATCHDOG_REPO        override repo for gh calls (derives <repo-slug>)
       AUTOSPEC_WATCHDOG_STALE_SECS   stale threshold (default: 1800)
       AUTOSPEC_WATCHDOG_RECLAIM_SECS reclaim threshold (default: 10800)
```

Exit: always 0. Prints `service-watch: nudged=N reclaimed=N ...` summary.

### `heartbeat-write.sh`

Writes a per-repo-scoped heartbeat to `~/.autospec/process-heartbeats/<repo-slug>/<issue>.json`.

```
Usage: heartbeat-write.sh --issue <N> --step <step> [--branch <b>] [--pr <p>] [--repo <owner/repo>]
Env:   AUTOSPEC_REPO   repo override (owner/repo format)
```

### `heartbeat-read.sh`

Reads heartbeat files from the caller's repo-slug subdir only (zero cross-repo bleed).

```
Usage: heartbeat-read.sh [--issue <N>] [--repo <owner/repo>]
```

Without `--issue`: prints all heartbeat file paths in the repo's subdir (one per line).
With `--issue`: prints the JSON content of that heartbeat, or empty if not found.

### `listener-match.sh`

Pattern-matches a conversation snippet against autospec-listen trigger keywords.

```
Usage: bash listener-match.sh "<phrase>"              # word mode (default)
       bash listener-match.sh --classify "<phrase>"   # JSON classify mode
       echo "<phrase>" | bash listener-match.sh [--classify]
```

Word mode (default, back-compat) prints exactly one of `issue`, `spec`, `none`
and always exits 0.

Classify mode (`--classify`) emits a JSON object and always exits 0. It applies
the keyword-routing verb->skill map and an imperative-intent gate:

```
{"match":bool,"skill":"autospec-define|autospec-run|autospec-review|autospec|null",
 "trigger":"<verb>|null","intent":"imperative|incidental|none","confidence":0-1}
```

Verb->skill map: `design`/`new feature`/`spec` -> `autospec-define`;
`implement`/`build`/`ship` -> `autospec-run`; `review` -> `autospec-review`;
`autospec ...` -> `autospec`. The existing `file an issue` / `write a spec`
back-compat phrases route to `autospec-define`. The intent gate is biased to
false-negatives: past-tense, negated, interrogative, and descriptive uses are
suppressed (`match:false` / `intent:incidental`) so incidental mentions never
misfire a route.

```
       AUTOSPEC_FORCE_LLM         set to 1 to always use LLM path
```

Exit: 0 = success, 1 = usage/file error, 2 = LLM escalation failed.

## End-of-run gap remediation (`$AUTOSPEC_SCRIPTS_DIR`)

Backs `/autospec-run` Phase 5.5. See `docs/specs/2026-05-24-autospec-end-of-run-gap-remediation-design.md`.

### `run-batch-start.sh`

Records / reads the UTC run-start timestamp so Phase 5.5 can scope `/autospec-review --since`
to work shipped during THIS run. Stored at `~/.autospec/.run-batch-start` (ISO 8601 UTC).

```
Usage: bash run-batch-start.sh --write [--force]   # write now() unless file exists
       bash run-batch-start.sh --read              # echo stored timestamp (epoch sentinel if absent)
Env:   AUTOSPEC_STATE_DIR   state dir (default: ~/.autospec)
```

Exit: always 0 (best-effort; missing file on `--read` returns the epoch sentinel).

### `gap-json-lib.sh`

Shared helpers for the gap JSON contract `{gap_id, dimension, severity, file, line, title, body, dedupe_key}`.
Sourceable (exposes `gap_required_keys`, `gap_validate_object`, `gap_title_hash`) or runnable.

```
Usage: bash gap-json-lib.sh --validate-file <path>    # exit 0 if file holds a valid gap object
       bash gap-json-lib.sh --title-hash "<title>"    # print 10-char sha1 hex (dedupe fallback)
       bash gap-json-lib.sh --selftest
```

Exit: 0 = ok/valid, 1 = invalid object, missing file, or missing `jq`.

### `emit-gaps.sh`

Shapes evaluate-findings output into the gap JSON contract. Keeps only `verdict=="keep"`,
assigns stable `gap_id` (`G<n>`), fills a `dedupe_key` title-hash fallback when absent.

```
Usage: bash emit-gaps.sh --findings <path> --out <path>
```

Exit: 0 = success (empty/missing input writes an empty array), 1 = `jq` missing.

### `gap-remediation-loop.sh`

Files surviving gaps from a gap JSON as `auto-implement,gap-remediation,priority:high` issues.
Dedupes each gap against open issues (matching `dedupe_key`/title and active `docs:drift`
self-heal labels), then classifies survivors via classify-model-fit backfill. Round state in
`~/.autospec/gap-round-state.json`, capped at `AUTOSPEC_GAP_MAX_ROUNDS` (default 2).

```
Usage: bash gap-remediation-loop.sh --gaps <path> --file
Env:   AUTOSPEC_STATE_DIR        state dir (default: ~/.autospec)
       AUTOSPEC_GAP_REPO         repo slug for gh (default: gh repo context)
       AUTOSPEC_GAP_MAX_ROUNDS   hard round cap (default: 2)
```

Exit: 0 = success (best-effort), 2 = `gh` CLI absent (cannot file issues).

## Shared-memory tooling (`$AUTOSPEC_SCRIPTS_DIR`)

Backs the cross-tool memory floor. See `docs/specs/2026-05-23-autospec-cross-tool-memory-design.md`.
Every script is best-effort: missing optional deps (mempalace, gh) are a silent skip, never a failure.

### `mempalace-compress.sh`

Triggers AAAK compression (`mempalace compress`) when a memory dir exceeds a LOC threshold.

```
Usage: bash mempalace-compress.sh --dir <path> [--threshold <loc>] [--dry-run] [--quiet]
Env:   AUTOSPEC_COMPRESS_THRESHOLD   fallback threshold (default: 5000)
```

Exit: always 0 (mempalace absence is a silent skip).

### `mine-pr-history.sh`

Extracts memory-worthy lessons from merged PR descriptions (`body:lesson:` patterns) into
`docs/memory/lesson_<slug>.md`. Idempotent — deduped by PR number in frontmatter.

```
Usage: bash mine-pr-history.sh --repo <owner/repo> --output-dir <dir> [--quiet]
Env:   AUTOSPEC_MINE_PR_HISTORY   must be "1" to enable (off by default)
       AUTOSPEC_MINE_MIN_BODY     minimum PR body length (default: 200)
       AUTOSPEC_MINE_LIMIT        max PRs scanned per run (default: 200)
```

Exit: always 0 (gh absence / failures are non-blocking).

### `inject-relevant-memory.sh`

Greps `docs/memory/*.md` for keyword matches and emits the top-k filenames + first 200 chars
as a context block for skill-prompt injection. Falls back to mempalace search when the CLI is present.

```
Usage: bash inject-relevant-memory.sh --context "<keywords>" [--top-k N] [--memory-dir DIR]
Env:   AUTOSPEC_MEMORY_DIR   override memory directory (default: auto-detected)
```

Exit: always 0 (missing dir / no matches are silent no-ops).

### `diary-write.sh`

Writes an episodic diary entry to `docs/memory/diary/YYYY-MM-DD.md` (append-safe; one file per day).

```
Usage: bash diary-write.sh --phase <n> --event <slug> --body <markdown> [--memory-dir <path>]
Env:   AUTOSPEC_SKIP_DIARY=1             skip entirely
       AUTOSPEC_SKIP_DIARY_MEMPALACE=1   skip the mempalace diary_write call
```

Exit: always 0 (best-effort; never blocks the caller).

### `ensure-tool.sh`

Best-effort idempotent installer for autospec's optional CLI deps via a platform fallback chain
(brew / apt-get / npm / pipx / uv / pip). Baked-in tool table: `bats`, `jq`, `gh`, `mempalace`.

```
Usage: bash ensure-tool.sh <tool>
Env:   AUTOSPEC_SKIP_ENSURE_TOOL=1          disable ALL auto-installs
       AUTOSPEC_SKIP_ENSURE_TOOL_<TOOL>=1   disable auto-install for one tool
```

Exit: always 0 (best-effort by design; unknown tools are a silent no-op).

### `cross-repo-index.sh`

Registers the current repo into `~/.autospec/memory-index/<slug>`. Idempotent, and GCs stale
entries whose `docs/memory/` no longer exists.

```
Usage: bash cross-repo-index.sh [--repo-root DIR] [--index-dir DIR]
Env:   AUTOSPEC_SKIP_CROSS_REPO_INDEX=1   skip registration silently
```

Exit: always 0 (best-effort; errors are silent).

### `cross-repo-search.sh`

Searches memory files across all indexed repos (`mempalace search`, falling back to `grep -r`),
tagging each hit with its source repo slug.

```
Usage: bash cross-repo-search.sh "<query>" [--index-dir DIR] [--top-k N]
Env:   AUTOSPEC_SKIP_CROSS_REPO_INDEX=1   skip search (exits 0 empty)
```

Exit: always 0 (no matches is a silent no-op).

### `detect-monitor-exit-mode.sh`

Classifies a halted Phase-4 monitor by inspecting worktree state, GitHub label/PR state, and the
latest heartbeat's tool-call count. Prints exactly one of `silent-exit`, `prompt-overflow`,
`clean`, `unknown`. Auditable encoding of `docs/memory/feedback_monitor_silent_exit.md` — keep
the two in sync.

```
Usage: bash detect-monitor-exit-mode.sh [--repo OWNER/NAME]
Env:   AUTOSPEC_WATCHDOG_DIR        heartbeat root (default: ~/.autospec/process-heartbeats)
       AUTOSPEC_OVERFLOW_THRESHOLD  tool-call count that signals overflow (default: 180)
```

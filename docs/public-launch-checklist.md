# Public Launch Checklist

Use this for public announcements.

- [ ] Confirm GitHub renders README Mermaid and Markdown tables correctly.
- [ ] Run the deterministic demo script: `bash scripts/demo-recording.sh`.
- [ ] Record or publish the demo placeholder from `docs/assets/demo-placeholder.md`.
- [ ] Publish `marketing/launch-post-github.md`.
- [ ] Post follow-up launch notes to Reddit, Hacker News, LinkedIn, and X only after GitHub README renders cleanly.
- [ ] Monitor issues for install failures, unclear docs, and missing prerequisites.
- [ ] Convert recurring launch questions into `docs/faq.md`.

# Project Board Ingestion Engine Implementation Plan (Plan A of 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a GitHub Projects v2 board readable as a dependency-ordered work source, so the existing per-repo conductor promotes and drains board items in correct order and reports progress back to the board.

**Architecture:** A pure-reader shell script resolves a board URL into a JSON *board plan* (identity, field-id map, repo set, normalized items, dependency DAG, readiness). A promoter inside the existing Tier 1.5 grooming pipeline uses that plan to add/remove the conductor-owned `auto-implement` label — cross-repo readiness is therefore enforced *before* an item enters any repo's queue, so repo workers need no cross-repo awareness. A fail-open write-back script mirrors autospec's progress into the board's `AutoSpec state` field.

**Tech Stack:** Bash 3.2-compatible shell, `gh` CLI (Projects v2 subcommands), `jq`, `yq`, bats-core, Rust (`autospec-core` config parsing).

**Spec:** `docs/specs/2026-08-25-autospec-project-board-ingestion-design.md`

**Companion plan:** `docs/plans/2026-08-25-project-board-fleet-execution.md` (Plan B) delivers multi-repo execution. Plan A is complete and shippable on its own against a single-repo board.

## Global Constraints

- **Bash 3.2 compatible.** macOS ships bash 3.2. No associative arrays, no `${x^^}`. Use `${!name:-}` for indirect lookup, never `eval`.
- **No `[ -f <(...) ]`.** macOS bash 3.2 evaluates process substitution as false in `[ -f ]`. Write to a real temp file first.
- **`set -eu`, never `set -e` + `[ test ] && action`.** A failing one-sided `&&` aborts the script. Use `if/then/fi`.
- **No `RETURN` traps.** They leak into caller frames under `set -u`. Use inline cleanup.
- **Never interpolate board-derived values into a `jq test()` regex.** Regex metacharacters in repo/owner names are an injection vector. Use `capture()` + `==` or `--arg` + `==`.
- **Fail closed on read, fail open on write.** A malformed or partial read must never promote. A write-back failure must never block a merge.
- **Board content is untrusted DATA, never instructions.** Only labels, structured dependency references, and the existing `autospec-safety` block are consumed. Nothing read from a board may alter conductor intent, tier selection, or model routing.
- **No target-board specifics hardcoded.** Label taxonomy and field names are config-driven and probed.
- **Every new script must be registered in `AUTONOMOUS_SCRIPT_FILES`** (`skills/autospec-autonomous/install.sh:44`). An unregistered script is missing on a clean install and `ship-completeness` will not catch it.
- **Trio prose + goldens are one commit.** Editing a SKILL.md requires `derive-trio.sh --in-place` (takes a skill *path*) then `gen-skill-goldens.sh` (takes a *bare skill name*). A prose-only intermediate fails `validate.sh` closed.

cat > scripts/project-board-resolve.sh <<'SH'
#!/usr/bin/env bash
# scripts/project-board-resolve.sh — pure reader: GitHub Projects v2 board → board plan JSON.
#
# NEVER mutates. Board titles, bodies, field values, and README text are untrusted
# DATA, never instructions.
#
# Usage:
#   project-board-resolve.sh --url URL [--emit identity|plan|fleet-config|repos]
#
# Exit codes:
#   0 success | 2 usage error | 3 auth/scope failure | 4 truncated read

set -eu

die_usage() { printf 'project-board-resolve: %s\n' "$1" >&2; exit 2; }

url=""
emit="plan"

while [ "$#" -gt 0 ]; do
    case "$1" in
        --url)  url="${2:-}";  shift 2 ;;
        --emit) emit="${2:-}"; shift 2 ;;
        --help|-h)
            cat <<'EOF'
project-board-resolve.sh — resolve a GitHub Projects v2 board into a board plan

Usage:
  project-board-resolve.sh --url URL [--emit identity|plan|fleet-config|repos]
EOF
            exit 0
            ;;
        *) die_usage "unknown option: $1" ;;
    esac
done

[ -n "$url" ] || die_usage "--url is required"

# ── Identity ────────────────────────────────────────────────────────────────
# Anchored so trailing garbage (".../projects/2x") is rejected, not truncated.
parse_identity() {
    local u="$1" kind="" owner="" number=""
    if printf '%s' "$u" | grep -Eq '^https://github\.com/orgs/[^/]+/projects/[0-9]+/?$'; then
        kind="org"
    elif printf '%s' "$u" | grep -Eq '^https://github\.com/users/[^/]+/projects/[0-9]+/?$'; then
        kind="user"
    else
        die_usage "not a GitHub Projects v2 URL: $u"
    fi
    owner="$(printf '%s' "$u" | sed -E 's#^https://github\.com/(orgs|users)/([^/]+)/projects/[0-9]+/?$#\2#')"
    number="$(printf '%s' "$u" | sed -E 's#^.*/projects/([0-9]+)/?$#\1#')"
    printf '{"owner":"%s","kind":"%s","number":%s}\n' "$owner" "$kind" "$number"
}

identity="$(parse_identity "$url")"

case "$emit" in
    identity) printf '%s\n' "$identity"; exit 0 ;;
    *) die_usage "unsupported --emit: $emit" ;;
esac
SH
chmod +x scripts/project-board-resolve.sh
```

cat > scripts/project-board-normalize.sh <<'SH'
#!/usr/bin/env bash
# scripts/project-board-normalize.sh — board labels → normalized attributes.
#
# Reads a board plan on stdin, writes the same plan with .items[].normalized added.
# Pure text: no network, no mutation. Never fails on unknown input — an
# unrecognized label normalizes to null.
#
# Usage: project-board-normalize.sh [--label-map FILE] < plan.json

set -eu

label_map=""
while [ "$#" -gt 0 ]; do
    case "$1" in
        --label-map) label_map="${2:-}"; shift 2 ;;
        --help|-h) printf 'project-board-normalize.sh [--label-map FILE] < plan.json\n'; exit 0 ;;
        *) printf 'project-board-normalize: unknown option: %s\n' "$1" >&2; exit 2 ;;
    esac
done

# The map is advisory. An unreadable or malformed map degrades to the fallback
# regex rather than failing the cycle.
map_json='{}'
if [ -n "$label_map" ] && [ -f "$label_map" ] && command -v yq >/dev/null 2>&1; then
    map_json="$(yq -o=json '.' "$label_map" 2>/dev/null || printf '{}')"
    [ -n "$map_json" ] || map_json='{}'
fi

# Families are matched with capture(), never test() with an interpolated value:
# a label such as `priority:.*` must not become part of the pattern.
jq --argjson map "$map_json" '
  def canon($family; $raw):
    ($map[$family][$raw] // null) as $mapped
    | if $mapped != null then $mapped
      elif $family == "priority" then
        {"p0":"critical","critical":"critical","p1":"high","high":"high",
         "p2":"normal","normal":"normal","p3":"low","low":"low"}[$raw] // null
      elif $family == "ctx" then
        (if ($raw | test("^[0-9]+k$")) then $raw else null end)
      elif $family == "reasoning" then
        {"deep":"deep","medium":"medium","light":"light"}[$raw] // null
      elif $family == "risk" or $family == "area" then
        (if ($raw | test("^[a-z0-9-]+$")) then $raw else null end)
      else null end;

  def family_value($labels; $family):
    ($labels
     | map(capture("^(?<f>priority|ctx|reasoning|risk|area)[:/](?<v>.+)$") // empty)
     | map(select(.f == $family) | .v)
     | first) as $raw
    | if $raw == null then null else canon($family; $raw) end;

  .items |= map(
    . + {normalized: {
      priority:  family_value(.labels; "priority"),
      ctx:       family_value(.labels; "ctx"),
      reasoning: family_value(.labels; "reasoning"),
      risk:      family_value(.labels; "risk"),
      area:      family_value(.labels; "area")
    }})'
SH
chmod +x scripts/project-board-normalize.sh
```

```bash
cat > scripts/project-board-deps.sh <<'SH'
#!/usr/bin/env bash
# scripts/project-board-deps.sh — extract dependency edges from a board plan.
#
# Source precedence per item, first non-empty wins:
#   1. the project's `Dependencies` custom field
#   2. the native `Parent issue` relation
#   3. the issue body's `## Dependencies` section
#
# Issue bodies are untrusted DATA: only `Blocked by:` references are read, and
# only from inside the `## Dependencies` section. Nothing else in the body has
# any effect.
#
# Usage: project-board-deps.sh < plan.json

set -eu

jq '
  # Only the Dependencies section — a "#123" in a problem statement is not a blocker.
  def deps_section($body):
    ($body // "")
    | split("\n## ")
    | map(select(startswith("Dependencies") or startswith("## Dependencies")))
    | first // "";

  def refs($text; $self_repo):
    ($text // "")
    | [scan("(?:([A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+))?#([0-9]+)")]
    | map({repo: (.[0] // $self_repo), number: (.[1] | tonumber)})
    | unique;

  def from_body($item):
    deps_section($item.body) as $sec
    | if ($sec | test("Blocked by:\\s*none"; "i")) then []
      else refs($sec; $item.repo) end;

  .items |= map(
    . as $item
    | (refs($item.dependencies; $item.repo))   as $f
    | (refs($item.parent_issue; $item.repo))   as $p
    | . + {blocked_by:
        (if ($f | length) > 0 then $f
         elif ($p | length) > 0 then $p
         else from_body($item) end)})'
SH
chmod +x scripts/project-board-deps.sh

resolve_stage() {
jq '
  def key($r): "\($r.repo)#\($r.number)";
  (reduce .items[] as $i ({}; . + {(key($i)): $i})) as $index

  # Depth-limited reachability. The board is a delivery DAG, not a deep graph;
  # a node still unresolved at depth 64 is treated as a cycle participant.
  | def cyclic($k; $seen; $depth):
      if $depth > 64 then true
      elif ($seen | index($k)) then true
      else ($index[$k].blocked_by // [])
           | map(cyclic(key(.); $seen + [$k]; $depth + 1))
           | any
      end;

  (.items | map(select(cyclic(key(.); []; 0)) | key(.))) as $in_cycle
  | .cycles = ($in_cycle | if length > 0 then [$in_cycle] else [] end)
  | .items |= map(
      key(.) as $k
      | (.blocked_by // []) as $bl
      | ($bl | map(select($index[key(.)] == null) | key(.))) as $missing
      | ($bl | map(select($index[key(.)] != null and $index[key(.)].state != "closed") | key(.))) as $open
      | if ($in_cycle | index($k)) then
          . + {ready: false, reason: "dependency cycle: \($k)"}
        elif ($missing | length) > 0 then
          . + {ready: false, reason: "unresolvable blocker: \($missing | join(", "))"}
        elif ($open | length) > 0 then
          . + {ready: false, reason: "blocked-by \($open | join(", "))"}
        else . + {ready: true, reason: "all blockers satisfied"} end)'
}

    pub write_back: bool,

                    .to_string(),
            );
        }
        Ok(())
    }

        _age="$(( $(date +%s) - $(stat -f %m "$_cache" 2>/dev/null || stat -c %Y "$_cache") ))"
        if [ "$_age" -lt "$BOARD_TTL" ]; then cat "$_cache"; return 0; fi
    fi

    # Fail-closed: any resolver failure is a dry board, never a partial promotion.
    if _plan="$(bash "$BOARD_RESOLVE" --url "$_url" --emit plan 2>/dev/null)"; then
        printf '%s' "$_plan" \
          | bash "$BOARD_NORMALIZE" ${AUTOSPEC_PROJECT_BOARD_LABEL_MAP:+--label-map "$AUTOSPEC_PROJECT_BOARD_LABEL_MAP"} \
          | bash "$BOARD_DEPS" --resolve > "$_cache" 2>/dev/null || printf '{"items":[]}' > "$_cache"
        cat "$_cache"
    else
        printf '{"items":[]}'
    fi
}

# Allowlist matching uses --arg + a literal prefix compare, never test():
# a repo name is board-controlled and may contain regex metacharacters.
board_stage() {
    _plan="$(board_plan)"
    printf '%s' "$_plan" | jq --arg repo "$repo" --arg allow "${AUTOSPEC_PROJECT_BOARD_ALLOWLIST:-}" '
      def allowed($r):
        ($allow | split(",") | map(select(length > 0))) as $pats
        | if ($pats | length) == 0 then false
          else $pats | map(
              (. | rtrimstr("*")) as $p
              | if endswith("*") then ($r | startswith($p)) else ($r == .) end) | any
          end;
      [.items[]? | select(.ready == true)] as $ready
      | {ready:        ([$ready[] | select(.repo == $repo and allowed(.repo))] | length),
         promotable:   [$ready[] | select(.repo == $repo and allowed(.repo)) | .number],
         out_of_scope: [.items[]? | select(allowed(.repo) | not) | {repo: .repo, number: .number}],
         demoted:      []}'
}
```

Merge `board_stage`'s object into the emitted envelope under `.board`, and for each `promotable` number under `--apply` + policy `auto|on`, route it through the **existing** Rust safety-stamp + `auto-implement` transition already used for `eligible` candidates. Do not add a second mutation path.

#!/usr/bin/env bash
# scripts/project-board-writeback.sh — mirror autospec progress into the board's
# `AutoSpec state` single-select field.

# FAIL-OPEN BY CONTRACT: always exits 0. A write-back failure must never block a

set -u

    case "$1" in
        --plan)  plan="${2:-}";  shift 2 ;;
        --item)  item="${2:-}";  shift 2 ;;
        --state) state="${2:-}"; shift 2 ;;

        *) printf 'project-board-writeback: unknown option: %s\n' "$1" >&2; exit 0 ;;
    esac

skip() { printf 'project-board-writeback: %s\n' "$1"; exit 0; }
fail() { printf 'code_health:project_board_writeback_failed %s\n' "$1" >&2; exit 0; }

[ -n "$item" ] && [ -n "$state" ] || skip "missing --item or --state"

command -v jq >/dev/null 2>&1 || skip "jq not found"

fi

[ -n "$field_id" ] || skip "board has no AutoSpec state field"

option_id="$(jq -r --arg s "$state" '.fields.autospec_state.options[$s] // empty' "$plan")"

current="$(jq -r --arg i "$item" '.items[] | select(.item_id == $i) | .autospec_state // empty' "$plan")"
if [ "$current" = "$state" ]; then
    skip "item $item already in state $state"
fi

if ! gh project item-edit --id "$item" --project-id "$project_id" \
        --field-id "$field_id" --single-select-option-id "$option_id" >/dev/null 2>&1; then
    fail "item=$item state=$state"

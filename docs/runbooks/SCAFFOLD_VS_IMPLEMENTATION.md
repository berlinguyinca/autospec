# Scaffold vs Implementation

Scaffolded means Autospec generated a plan, spec, template, issue draft, metadata update plan, or partial file structure.

Implemented means working runtime code was changed and verified by tests, rule recheck, and verifier review.

Autospec must not conflate the two. AI/NLAI runtime systems, database migrations, auth/security changes, dependency upgrades, and uncertain stack-specific UI generation remain scaffold/spec-first unless a bounded recipe, confident stack profile, patch plan, validation path, and verifier approval all exist.

Verifier v4 reviews recipe execution, patch plan compliance, template application safety, stack confidence, rule recheck evidence, and scaffold honesty.

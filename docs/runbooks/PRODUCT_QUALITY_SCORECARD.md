# Product Quality Scorecard

The product quality scorecard is a heuristic rollup, not a certification.

```bash
bash scripts/autospec-product-quality-scorecard.sh --dry-run
bash scripts/autospec-runtime-evidence-status.sh
```

It summarizes product intent, architecture, testing, UI/UX, accessibility, documentation, tutorials, reporting, analytics, AI, NLAI, diagnostics, security/privacy, operations, metadata, and autonomy readiness.

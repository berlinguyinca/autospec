# AI and NLAI Runtime Shells

AI/NLAI runtime shells generate UI/spec structure only unless an existing safe provider or data pattern is detected.

Supported v1 shells include AI provider settings, token usage dashboard, RAG assistant shell, MCP diagnostics shell, NLAI capability interface, pretty rendering viewers, data query shell, and file operations shell.

Generated shells do not display API key values, do not persist secrets, do not call providers by default, do not execute SQL, and do not create database migrations.

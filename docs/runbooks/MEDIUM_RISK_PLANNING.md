# Medium-Risk Planning

Medium-risk work is planned, not executed automatically.

```bash
bash scripts/autospec-medium-risk-plan.sh --dry-run --issue <number>
bash scripts/autospec-build-guidance-request.sh --dry-run --issue <number>
```

Plans include scope, non-goals, architecture, ADR needs, security/privacy impact, test strategy, evidence strategy, rollback, decomposition, human decisions, and acceptance criteria.

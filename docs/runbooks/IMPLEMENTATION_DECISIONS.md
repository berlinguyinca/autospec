# Implementation Decisions

Implementation Decision Records explain why Autospec selected a capability, recipe, adapter, plan, or refusal.

```bash
bash scripts/autospec-record-implementation-decision.sh --dry-run --issue <number>
bash scripts/autospec-record-implementation-decision.sh --confirm --issue <number>
```

IDRs live under `docs/idrs/` when confirmed and are indexed in `.autospec/state/implementation-decisions.json`.

## Lifecycle
Standalone Pi or optional AutoSpec / GitHub / Herdr entry -> complexity/risk assessment -> plan revision and existing issue discovery/linkage -> optional Plannotator pre-implementation review (skip/offer/require by policy, explicit override, exact plan digest, changes requested replan, required unavailable blocks) -> Pi independent scout/implement/review workers in isolated worktrees -> verified checkpoints and handoffs -> GitHub PR -> independent AI post-PR review/specialist quorum -> repair and re-review after head SHA changes -> CI and guarded merge -> evidence-backed completion and optional learning. AutoSpec supplies task DAG and policies when enabled; Pi remains execution authority; GitHub owns issue/PR state; Plannotator owns plan decision; CI owns build result; HCN owns room/message authorization; Herdr is secure projection/command gateway, not another orchestrator.

## Room/workspace/tab/pane behavior
One HCN room links one or more existing Herdr workspaces, with explicit grants and one primary room per workspace; a workspace may be linked to multiple rooms. Primary agents appear as workspace tabs, spawned subagents as panes; long-lived/remote agents may use their own tabs but preserve lineage. Closing pane never kills agent. Contextual HCN threads attach to graph nodes; do not duplicate messages. Room access never implies workspace terminal access. External coworker Claude/Pi agents and remote A2A agents get virtual tabs/panes with externally reported status, no fake terminal. Existing HCN A2A is text-only send; extend existing HCN service for scoped accept/decline/progress/result/cancel and artifact proposals, no second task store. Local bridges connect outbound; no peer shell access.

## Security
Effective permission is intersection of user, agent, device, room, workspace, task and artifact grants. External messages untrusted and never executable. Cross-user delegation bounded by TTL, budget, max turns, hop count, approval and cycle detection. Verify access for graph traversal/search/replay/notifications, redact logs/secrets, use immutable artifact revisions and CAS promotion. Require exact commit/plan digest review binding; deny on ambiguous lease or required review unavailable. Server-to-server federation separate later gated feature, not implied by external agent participation.

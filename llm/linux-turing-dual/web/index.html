Only one model is resident at a time (--models-max 1). Asking for a different id costs a reload — about 7 s for a 27B off NVMe. Every reload shows up as an eviction above.

How to connect

Reasoning tokens. These models emit reasoning before content, so max_tokens: 16 returns empty content — all of it went to reasoning. Either allow headroom (512+) or send "chat_template_kwargs": {"enable_thinking": false}.
Context tiers are a contract, not a limit. Nothing enforces them. A -100k id means run solo; -40k/-50k mean two sessions. A 100k session beside a 40k one over-subscribes the shared pool and both die together.

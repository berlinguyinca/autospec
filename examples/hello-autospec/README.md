# Hello AutoSpec

This example shows the shape of a tiny AutoSpec run without touching GitHub.

Files:

- `spec.md` - a small feature request written as a design spec.
- `sample-issue.md` - the implementation issue an agent could receive.
- `expected-closeout.md` - the closeout report shape expected after implementation.

Use it with:

```bash
bash scripts/demo-recording.sh
```

# Demo Video Script

## 0:00 - Problem

AI coding agents can create large diffs quickly, but maintainers still need specs, scoped issues, validation evidence, and a review trail.

## 0:30 - What AutoSpec Is

AutoSpec is a workflow suite for Claude Code, Codex CLI, and OpenCode. It helps structure agent work from request to spec to issues to PRs.

## 1:00 - Quickstart

Show `README.md`, then run:

```bash
bash scripts/demo-recording.sh
```

## 1:30 - Example

Open `examples/hello-autospec/spec.md`, `sample-issue.md`, and `expected-closeout.md`.

## 2:30 - Architecture

Open `docs/assets/architecture.mmd` and explain the flow.

## 3:15 - Safety

Open `SAFETY.md` and explain that AutoSpec supports evidence-based delegation, not blind production changes.

## 4:00 - Call To Action

Ask viewers to try the quickstart, file unclear-docs issues, and star the repository if the workflow is useful.
